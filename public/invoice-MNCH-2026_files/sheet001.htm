2 Mentorship Lifecycle Module 95,000.00
– The largest part of the app — covers everything a mentor needs to run an on-site mentorship programme from start to finish.
– Mentors create a new mentorship by following a step-by-step wizard: choose the facility, select the programme, assign a co-mentor, and set dates.
– Within each mentorship, mentors manage classes — start a class, add training modules, and formally close it once complete.
– For each module, the mentor marks attendance for each mentee (present or absent) with an option to mark everyone at once.
– Session notes can be added to record what was covered or any important observations during a session.
– Mentors can add existing staff as mentees, create new mentee accounts, remove participants, and generate a self-enrolment link.
– Mentees see only their own classes, their progress through each module, and upcoming sessions.
– A reports tab gives mentors a summary of attendance rates, modules completed, and how each mentee is progressing.
3 Global Trainings Module 20,000.00
– A separate section for national and county-level training events organised centrally — distinct from on-site facility mentorships.
– Users browse upcoming and past trainings, see full details (dates, location, objectives), and enrol themselves if eligible.
– Participants confirm their attendance directly through the app, keeping records up to date without paperwork.
– Has its own navigation and visual style, clearly separate from the mentorship area to avoid confusion.
4 Offline Mode & Automatic Background Sync 140,000.00
– The app works fully with no internet — mentors in remote facilities can fill in data, mark attendance, and manage mentorships without any data connection or Wi-Fi.
– Everything done offline is saved securely on the phone and sent to the server automatically the moment a connection becomes available — no action needed from the user.
– On startup the app loads instantly from data already on the phone — users can start working immediately without waiting for internet.
– If internet becomes available mid-task, the app syncs in the background without interrupting or slowing down what the user is doing.
– All action types work offline — forms, attendance, session notes, adding mentees, starting or ending a class, and enrolling in trainings. Each is queued and sent in the correct order once connectivity returns.
– The app only downloads what has changed since the last sync, keeping the process fast and not consuming unnecessary data bundles.
– If a record was created offline and the server later assigns it a permanent ID, the app silently updates its local copy — no duplicate records or mismatches.
– A small badge shows how many changes are waiting to be synced; a brief notification appears when new server data has been received.
– On log out, all locally stored data is securely wiped from the phone so no sensitive health records remain on a shared or lost device.
– All data (mentorships, classes, attendance, user info, training schedules, app settings) is stored locally in separate areas so the full app works at all times regardless of connectivity.
