Facility Assessment Module
  • Allows health workers to carry out structured assessments of a facility across six areas: Infrastructure, Skills Lab, Human Resources, Health Products, Information Systems, and Quality of Care.
  • The assessment form guides the user through one section at a time, asking only the questions that are relevant based on previous answers — so the form adapts as the user fills it in.
  • Includes dedicated data-entry screens for recording staff numbers by cadre and tracking availability of health commodities and medical supplies.
  • Once complete, the app generates a scored report showing how the facility performed in each area, colour-coded as Good, Fair, or Poor, with a visual score ring and trend chart.
  • The report highlights which area needs the most attention and allows the user to download it as a PDF or send it by email directly from the app.

Mentorship Lifecycle Module
  • The largest and most involved part of the app — covers everything a mentor needs to run an on-site mentorship programme from start to finish.
  • Mentors can create a new mentorship programme by following a step-by-step setup wizard: choose the facility, select the training programme, assign a co-mentor, and set the dates.
  • Within each mentorship, mentors manage classes — they can start a class, add training modules to it, and formally close it once done.
  • For each module in a class, the mentor can view sessions and mark attendance for each mentee — who was present and who was absent — with the option to mark everyone at once.
  • Session notes can be added to record what was covered or any important observations during a training session.
  • Mentors can add existing staff as mentees, create new mentee accounts directly from the app, remove participants, and generate a link that allows mentees to enrol themselves without needing the app.
  • Mentees log in to see only their own classes, their progress through each module, and their upcoming sessions.
  • A reports tab gives mentors a summary of attendance rates, how many modules have been completed, and how each mentee is progressing across the programme.

Offline Mode & Automatic Background Sync
  • The app works fully even when there is no internet connection — mentors in remote facilities can fill in assessments, mark attendance, and manage mentorships without needing data or Wi-Fi.
  • Everything the user does while offline is saved securely on their phone and sent to the server automatically the moment a connection becomes available, with no action needed from the user.
  • When the app opens, it loads instantly using data already saved on the phone — the user does not have to wait for the internet before they can start working.
  • If a user fills in a form offline and connectivity comes back while they are still on that screen, the data syncs in the background without interrupting what they are doing.
  • A small indicator appears on screen when there are unsaved changes waiting to be sent, so the user always knows the status of their data.
  • When new data from the server arrives — for example, a co-mentor has updated a class — the app shows a brief notification at the bottom of the screen to let the user know.
  • All data is stored in an organised local database on the device covering assessments, mentorships, attendance records, user information, and training schedules, so the full app experience is available at all times regardless of connectivity.
